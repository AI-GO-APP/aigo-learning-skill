## 驗證邊界

課程檢查防止錯帳號、錯 App 或群組的誤操作，不是獨立資料沙箱。Builder 的 Custom 同步／刪除遠端檔案／編譯／發布有課程目標檢查；資料工具、直接 HTTP、介面操作與 Hosted Actions 仍須遵循課程前置核對及平台授權，不宣稱所有寫入均被攔截。
本輪沒有登入或修改正式租戶；沒有以原生 Claude Code／Codex 開新對話實測自動發現。安裝路徑、升級、技能行為與 CI 分別驗證，正式匿名權限、部署及預約資料流仍須在已開通環境驗收。
發版須另外通過線上 CI、重新下載 release 驗證雜湊，以及舊 0.3.1 更新器跨版到 0.4.0 的安裝與保留測試；收據留在課程工作區。

## 發版查核邊界

本機測試及前向測試不登入或修改 AI GO 正式租戶。Hosted 的真實部署、匿名資料授權及完整預約業務流程仍須由學員在自己的已開通環境實測；不可用本文件、scope check 或 CI 成功代替。

發版須通過 GitHub CI，重新下載 release 資產驗證 SHA-256，並在獨立暫存安裝實測由 0.2.1 更新至 0.3.0、節流與工作區保留。實際收據保存在維護者發行紀錄。
