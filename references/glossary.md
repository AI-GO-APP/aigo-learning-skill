# 統一用詞與白話解釋

| 名詞 | 先怎麼跟學員說 | 精確界線 |
|---|---|---|
| 普通版 | 以完成實際專案交付為主的 Builder 技能 | 統一使用「普通版」這個名稱 |
| 學生學習版 | 邊做成果、邊練習理解與修改的課程技能 | 不是 AI GO 另一個隔離平台；技能 id 仍是 aigo-learning |
| 租戶 | 你的公司／課程專用空間 | 網址由助教提供；不同空間另開工作區 |
| roles group | 助教幫你開好的專屬權限群組 | 名稱與 id 由助教提供；Custom App 建立後立即到存取設定手動選、回讀核對 |
| Custom App | 課程內部作業系統 | 本課採 internal；不能把這支內部 App 當匿名官網。Custom 另有其他存取形態，不宣稱所有 Custom 都不能對外 |
| Hosted App | 給客人開啟的網站／系統；有自己的程式服務 | 正式拼法 Hosted App，HostApp 視為相同意圖。匿名官網用 public，會員系統另定登入及授權 |
| SDK | 平台提供的工具包 | 不要求學生背 API；開發時保留平台既有工具，不任意覆蓋 |
| Server Action | 在平台伺服器上執行的工作 | 內部資料授權在這裡檢查；隱藏按鈕不代表資料受保護 |
| Data Reference | 這個 App 被允許使用哪些資料的清單 | 不能用租戶裡「有表」推定 App 已獲授權；Hosted 用隨附整合 id |
| published | 已發布的版本 | 舊版已發布不代表這次改動已上線，仍要測新行為 |
| 401 | 登入或身分驗證沒通過 | 檢查目前帳號、空間、憑證與版本，不印密碼 |
| 403 | 這個身分沒有此操作權限 | 不借助教帳號、不升權繞過；由 AI 排查範圍；系統故障走 Builder 平台問題回報 |
| Deploy Token | 只供指定 App 部署的專用金鑰 | 放自己 App repo 的 Actions secret，不能放程式、教材或網頁前端 |
| GitHub Actions／CI | 把程式檢查與部署交給自動流程 | Hosted 經分支、PR、合併後部署；Custom 仍走本機同步、編譯、發布 |

提示詞：
> 請用我正在做的內部系統和對外網站，白話解釋我不懂的名詞，各給一個例子，再請我用自己的話重述；不操作平台。
